# Solder · v1.0.2.9

## Стало удобнее

- Проверка обновлений ограничена пятью последними релизами, а во вкладке обновлений появилась ссылка на страницу релизов для ручного скачивания файлов.

## Исправлено

- Уменьшен расход памяти при проверке обновлений, а нехватка памяти больше не отображается как неподходящий ответ сервиса.
- Уменьшен размер прошивки веб-интерфейса, чтобы она помещалась в доступную память для обновления через OTA.

## Как обновить

Откройте «Обновления» в интерфейсе станции, выберите этот выпуск и установите обновления станции и веб-интерфейса по очереди. Во время установки не отключайте питание.

Выпуск предназначен для станций с веб-обновлением. Если у вашей станции нет этой функции, обратитесь к продавцу перед установкой.
