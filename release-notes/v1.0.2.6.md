# Solder · v1.0.2.6

## Стало удобнее

- На станциях с новым загрузчиком обновление передаётся на повышенной скорости с автоматическим снижением при ошибках связи, при этом поддержка прежних загрузчиков сохранена.

## Исправлено

- Скорректирован заводской температурный профиль C210 на V3 по контрольным замерам для уменьшения занижения показаний и перегрева относительно заданной температуры.

## Как обновить

Откройте «Обновления» в интерфейсе станции, выберите этот выпуск и установите обновления станции и веб-интерфейса по очереди. Во время установки не отключайте питание.

Выпуск предназначен для станций с веб-обновлением. Если у вашей станции нет этой функции, обратитесь к продавцу перед установкой.
