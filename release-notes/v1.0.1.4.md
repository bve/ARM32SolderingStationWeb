# Solder Web 1.0.1.4

First release in the dedicated **web-generation** update repository.

## Compatibility / Совместимость

- Requires the new station bootloader with the application at **0x8000**.
- **Do not install on legacy stations** with the application at **0x10000** and
  the old on-station update menu. Those stations keep using
  `bve/ARM32SolderingStation`; no updates are published there by this release.
- Select the station `.ota` matching the board revision: V1, V2 or V3.
  V3 uses different current-sense scaling; it is not an upgrade choice for V2.
- Factory provisioning images and keys are not included. Migrating a legacy
  station requires a separate service procedure and replacement of the
  bootloader and companion firmware, not this application package alone.

## Existing web-generation stations / Переход на новый канал

The already-installed web interface may still check the old repository.
Download `ARM32SolderingStationWeb-esp32c3-v1.0.1.4.espota` from this release,
upload it under **Updates → Web interface / Обновления → Веб-интерфейс**, and
confirm installation. Subsequent release checks use this new repository.

Companions with the older single-application partition layout need an initial
USB migration; a `.espota` cannot change that partition table.

Upload the matching station `.ota` separately under **Updates → Station**.
Do not use `/factory` for an ordinary update. Do not disconnect power during
installation. Attend the station and stop heating before updating.

## Included features / Возможности

- Station control and status from the web interface; English, Russian and Kazakh
  synchronized with the station language.
- Station settings, cartridge-specific temperature calibration with draggable
  curves, and temperature/power/voltage/current history charts.
- Wi-Fi setup, configurable access-point password and unique AP name suffix.
- Web interface self-update and encrypted station update packages for V1/V2/V3.
- Dedicated update channel isolated from legacy station releases.

`SHA256SUMS.txt` covers all four firmware packages. Station packages are
encrypted/authenticated; `.espota` is integrity-checked but not digitally signed.
Download only from this repository and update on a trusted local network.
