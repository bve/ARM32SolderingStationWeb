# Solder · v1.0.2.2

## Стало удобнее

- Графики используют постоянную шкалу от 0 до 500. Масштаб больше не меняется при колебаниях показаний, переключении линий и просмотре истории.
- График движется плавнее и восстанавливает показания после кратких обрывов связи. Медленное обновление страницы больше не уменьшает число записанных точек.

## Как обновить

Откройте «Обновления» в интерфейсе станции, выберите этот выпуск и установите обновления станции и веб-интерфейса по очереди. Во время установки не отключайте питание.

Выпуск предназначен для станций с веб-обновлением. Если у вашей станции нет этой функции, обратитесь к продавцу перед установкой.
