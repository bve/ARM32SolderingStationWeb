# Solder · v1.0.3.1

## Стало удобнее

- Фотографии в руководстве очищены от посторонних предметов, чтобы станция и органы управления были лучше видны.
- В руководстве пользователя иллюстрации заменены фотографиями станции, сжатыми для экономии памяти.

## Исправлено

- Температурные пресеты в веб-интерфейсе теперь загружаются и восстанавливаются после потери связи без остановки нагрева.

## Как обновить

Откройте «Обновления» в интерфейсе станции, выберите этот выпуск и установите обновления станции и веб-интерфейса по очереди. Во время установки не отключайте питание.

Выпуск предназначен для станций с веб-обновлением. Если у вашей станции нет этой функции, обратитесь к продавцу перед установкой.
