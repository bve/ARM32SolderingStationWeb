# Solder · v1.0.2.3

## Стало удобнее

- Для каждого графика задана своя постоянная шкала: температура 0–500 °C, напряжение 0–50 В, мощность 0–200 Вт и ток 0–15 А. Автомасштабирование отключено.
- На странице станции появились три кнопки быстрого выбора сохранённой температуры P1–P3. На странице обновлений показываются только пять последних релизов.

## Как обновить

Откройте «Обновления» в интерфейсе станции, выберите этот выпуск и установите обновления станции и веб-интерфейса по очереди. Во время установки не отключайте питание.

Выпуск предназначен для станций с веб-обновлением. Если у вашей станции нет этой функции, обратитесь к продавцу перед установкой.
